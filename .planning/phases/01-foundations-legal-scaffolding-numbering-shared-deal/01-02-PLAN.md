## Trust Boundaries

This plan writes one Markdown data file into a public repository. There is no runtime, no network
surface, no authentication, no data store, and no user input, so the ASVS L1 controls for session
management, access control, input validation, and cryptography have no counterpart here and are not
padded into the register. The boundaries that genuinely exist are content boundaries.

| Boundary | Description |
|----------|-------------|
| Invented example data -> public repository | A fictional company or person name could match a real entity once the repository is public. |
| Canonical figures table -> the brief's own prose and every later example | A figure stated in prose but absent from the table drifts silently across files. |
| The shared deal -> the Phase 5 benchmark | Facts chosen to flatter the rule catalog make the measured lift circular. |
| Real platform names -> comparative claims | Naming real products is permitted; comparing them creates the exposure INT-05 exists to prevent. |

## STRIDE Threat Register (ASVS L1, blocking on `high`)

|-----------|----------|-----------|----------|-------------|-----------------|
