line, the prose, and the register, and a check mode that returns a report of rule-cited blocks and
never a corrected document. Add the two-pass self-check, the register specification, and the Limits

existing behaviour rather than restructuring an output format Phase 4's committed examples were
already authored against. The two-pass self-check is what makes the project's named warning
sign — a self-check that only ever finds things to delete — structurally impossible instead of
discouraged.

tree no longer claims three shipped files are unwritten.
