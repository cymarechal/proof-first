The Agent Skills frontmatter allow-list — exactly six top-level keys, any key outside it is a hard
validation failure in the specification, not a soft warning:

| Key | Required | Constraint |
|---|---|---|
| `name` | yes | 1-64 chars, lowercase alphanumerics and hyphens, no leading or trailing hyphen, no double hyphen, **must equal the parent directory name** |
| `description` | yes | 1-1024 chars, non-empty |
| `license` | no | a license name or a pointer to a bundled license file |
| `compatibility` | no | 1-500 chars free text; this project omits it |
| `metadata` | no | free-form string-to-string map |
| `allowed-tools` | no | space-separated string; experimental |

Reuse, do not reinvent:
- `split_sections` (line 113), `table_rows` (line 133), `parse_numbering` (line 152) — proven
  against `NUMBERING.md` and `examples/deal-brief.md`.
- `parse_notices` (line 398) — the closest existing precedent for extracting a specific known shape
  without a general-purpose parser: it finds a fenced block and then scans an indented list line by
  line. `parse_frontmatter` follows that style.
- `_carrier_is_repo_relative` (line 383) — the existing path-traversal guard, to be reused if any
  frontmatter field ever carries a path. None does today.
- `_write` (line 798), `_good_numbering` / `_bad_numbering` (lines 803-857) — the self-test fixture
  pattern: a hand-built minimal document, never the real repository.
- `_insert_table_rows_after_heading` (line 604), `_mutate_dup_id` (line 621) — the mutation pattern.
- `SKILL_GLOB`, `parse_skill_catalog`, `parse_checklist`, `CATALOG_CHECK_CODES`,
  `run_catalog_checks` — added by 02-01; extend them rather than adding parallel machinery.

Hard contracts:
- A check function returns `list[(subject, "code-name message")]`; `mutation_test` recovers the code
  via `line.split(' ', 1)[0]`, so the message's leading token must be exactly the code string.
- `ALL_CHECK_CODES` (line 557) and `run_all_checks` (line 564) are the only aggregation points.
  `main()` and `mutation_test()` need no change.
- `self_test` (line 1083) writes a fixture at `skills/SKILL.md` — one level shallower than a real
  skill. Every new check must use the one-level `skills/*/SKILL.md` glob 02-01 established, never a
  recursive walk, or it fires on the known-good fixture.
- Absence is not failure. A repository with no `skills/*/SKILL.md` produces no violation from any of
  these codes; the checker runs green on a repo missing the files it will eventually validate.

The frozen stated-count template (02-01, P-03), matched as a whole line:
`This catalog contains {N} rules in {M} numbered sections.` N is the count of PF rows in
`NUMBERING.md`'s Allocated IDs table; M is the count of distinct PF sections among those rows.
