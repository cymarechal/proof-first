Close gap G-02-4: make the scope-hash guard in `evals/trigger/run_trigger_test.py` fail closed.

02-REVIEW.md's CR-01 found that the instrument's one load-bearing safety property — "an
observation recorded against a different description is not an observation of these rows, so a
mismatch halts" (the module's own docstring, lines 70-73) — is enforced only in the case where it
was already satisfied. The guard reads `if bound_hash and bound_hash != live_hash`, so a document
with no recorded binding yields `bound_hash is None`, the condition is falsy, and the run proceeds
with no verification at all. Separately, the regex that finds the binding scans the whole markdown
document rather than the `## Scope` section, so any future sha256 reference added earlier in the
file is adopted as the binding instead.

holds exactly one 64-hex token, `d5dd651a…`, and it matches `head -14 skills/proof-first/SKILL.md
| shasum -a 256`. Every figure in RESULTS-trigger.md was produced under a guard that happened to
be checking the right hash. What is being fixed is the guarantee, not the data.

### Task 1 — Scope the binding search to the `## Scope` section

```python
def recorded_scope_hash(md_text):
    """Pull the sha256 the Scope section binds the rows to. None if absent."""
    scope = re.search(r'^##\s+Scope\s*$(.*?)(?=^##\s|\Z)', md_text, re.M | re.S)
    if not scope:
        return None
    match = re.search(r'\b([0-9a-f]{64})\b', scope.group(1))
    return match.group(1) if match else None
```

### Task 2 — Extract the guard decision and make it fail closed

Add a pure decision function beside `resolve_out_mode()`, matching its shape and its
raise-on-refusal convention:

```python
def scope_binding_verdict(bound_hash, live_hash, path=None):
    """Decide whether the recorded rows are provably bound to the live description.

    CR-01: the earlier form of this check read `if bound_hash and bound_hash !=
    live_hash`, which is falsy when no binding was found at all -- so a document
    with a missing or malformed Scope hash ran with the guard silently skipped.
    An absent binding is now a refusal, not a pass.
    """
    label = path if path else 'the --tests file'
    if bound_hash is None:
        raise ValueError(
            '%s records no sha256 under its ## Scope heading, so its rows cannot be '
            'shown to belong to the live description. Add the binding before running.'
            % label
        )
    if bound_hash != live_hash:
        raise ValueError(
            '%s binds its rows to description sha256 %s but the live SKILL.md hashes to '
            '%s. The rows must be re-authored against the new description, not filled in.'
            % (label, bound_hash, live_hash)
        )
    return 'bound'
```

Rewrite the call site (lines 540-545) to use it, preserving the existing exit-1-with-stderr
behaviour:

```python
    bound_hash = recorded_scope_hash(md_text)
    try:
        scope_binding_verdict(bound_hash, live_hash, path=args.tests)
    except ValueError as exc:

        return 1
```
