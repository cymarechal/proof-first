<objective>
Build the mechanism DIST-05 asks for and the two artifacts DIST-03 and DIST-04 ask for: a stdlib-only
generator that derives a Claude Code output style and a paste-able system prompt from the shipped
skill content, stamps each with a content hash of its exact inputs, and a pair of CI-enforced codes
that make skipping the re-sync step a build failure.

Purpose: this is the one part of Phase 4 with no precedent to copy. The reference implementation this
project is modelled on hand-writes both derivatives, has no generator, no version stamp, no drift
check and no documented re-sync step — so "do what it does" fails DIST-05 by construction. Generating
both files from one recipe also lets the phase discharge its hardest success criterion honestly: the
claim that a user gets the same discipline through a channel with no skill support is discharged
**structurally**, by proving every shipped rule heading and every artifact-family heading reaches each
derivative, and the behavioural half is disclosed as unmeasured rather than asserted.

Output: `tools/generate_derivatives.py` with a `--check` mode CI runs; `output-styles/proof-first.md`
and `prompts/system-prompt.md`, both generated and hash-stamped; two new CI-enforced violation codes
with firing and silent fixtures and registered mutations; the discrimination-proven total moved from
37 to 39.
</objective>
