<objective>
Turn the three mechanizable defect classes `04-UAT.md` found in this repository's shipped example
prose into registered, discrimination-proven violation codes, so none of them can be reintroduced
behind a green gate.

Purpose: all seven gaps shipped through a 41-code green gate. `--self-test`, `--mutation-test`, the
bare run and `generate_derivatives.py --check` were all passing when a human-substitute adversarial
read found the prose defective. That is the finding that matters, and repairing the prose alone leaves
the repository able to reintroduce every one of those defects tomorrow. This project's thesis is that
a claim is worth what its evidence is worth; the same standard applies to its own checker. Where a gap
has a mechanizable signature, the code ships alongside the prose fix.

Output: `example-sentence-length` (PF-4.1's 25-word ceiling over both example files' ✓ columns),
`before-after-spelled-count` (word-spelled counts that route around the digit-shaped figure
interface), and `example-rule-narration` (an explicitly-labelled proxy for SKILL.md line 261). Each
carries a firing fixture, a silent fixture and a registered `MUTATIONS` entry. The
discrimination-proven total moves from 41 to 44.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository files → `check_repo.py` parsing | The checker reads contributor-authored Markdown and JSON. A malformed or adversarial file could in principle drive pathological regex behaviour or an unhandled exception that turns a real violation into a crash. |
| `mutation_test()` → filesystem | The harness copies a subset of the tree into a temporary directory and mutates the copy. A path-handling defect there could write outside the sandbox and damage the working tree. |
| CI runner → repository | The GitHub Actions job runs these commands with no secret and no network dependency beyond checkout. |
