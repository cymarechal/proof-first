<objective>
Build the deterministic proxy linter, and make its word list provably external before it counts
a single violation.

Purpose: EVAL-02 is the requirement that decides whether this whole phase's headline number
means anything. A buzzword list curated by reading this repository's own ✗ columns would make
the benchmark a closed loop — the skill would be measured against words the skill's own authors
chose because the skill deletes them. `.planning/STATE.md` has carried this as a standing
blocker since roadmap creation: *"Linter's buzzword-proxy word list (EVAL-02) must be sourced
independently from SKILL.md's own worked examples, or the Phase 5 benchmark becomes circular —
flag explicitly during Phase 5 planning, not left implicit."* This plan is where it stops being
a flag and becomes a mechanical gate.

The honest version of that gate is narrower than it first looks, and this plan states the narrow
version rather than the flattering one. Measured this session with `grep -ioF` over
`skills/proof-first/references/worked-examples.md` and `examples/before-after.md`: of eighteen
candidate terms drawn from the two external lists, nine already appear in this repository's own
example prose — `comprehensive` 5 times, `significant` 6, `enterprise-grade` 3, `best-in-class`
2, `world-class` 2, `cutting-edge` 2, `robust` 2, `seamless` 1, `leading` 1. That overlap is
expected and is not evidence of circularity: a skill that teaches writers to delete puffery will
naturally illustrate itself with the same puffery a public style guide names. What the registry
can prove is **provenance** — that every shipped term traces outward to Wikipedia's Words to
watch or to the GSA plain-language jargon list, and that none traces only inward to this
repository. It cannot prove a human never looked at `worked-examples.md` while choosing which
external-list entries to ship. That ceiling is written into the module docstring, in the same
sentence class `tools/check_repo.py` already uses for its own paraphrase-judgement ceiling.

Output: `evals/proxy-sources.md`, `evals/lint.py` with eight discrimination-proven violation
codes and the EVAL-03 disclaimer, and one new line in CI.
</objective>
